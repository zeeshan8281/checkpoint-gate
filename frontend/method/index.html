02

Hold out entire query families

600 synthetic tasks across three splits. Each split uses four different query families, with 50 tasks per family.

Train 200 tasks

Filter / group sum / missing child / join filter

Development 200 tasks

Conditional count / group having / top ties / correlated exists

Held-out test 200 tasks

Latest row / NULL-safe anti-join / distinct pairs / relational division

Each database has 12 parent rows and 52 child rows. Half of each family receives one transient first-call tool error.

03

Supervised training; no reward update

Rank-8 LoRA on Qwen3.6-35B-A3B used 96 assistant-turn demonstrations from 83 unique training tasks. We ran 12 supervised updates with batch size 8 and learning rate 4 × 10⁻⁵.

18reward groups sampled72trajectories evaluated0reward updates made

All four trajectories within each reward group received the same reward. With no within-group signal, every reward update was skipped. The results therefore compare base and SFT only.

05

A negative pilot, with clear limits

Supervised fine-tuning improved strict formatting but reduced SQL correctness on these held-out tasks. It does not establish that fine-tuning generally hurts SQL ability.

  • One training seed. Task-level Wilson and paired bootstrap intervals do not measure variation across seeds or new query families.
  • A narrow synthetic benchmark. Four related test families are not a broad capability evaluation; the public generator is not contamination-resistant.
  • Limited regression coverage. The elementary arithmetic-and-copy suite fell from 68% to 54%, but cannot establish general forgetting.
  • No reinforcement-learning result. Equal rewards prevented all reward updates. There is no trained RL condition to compare.
